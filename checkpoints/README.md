# Checkpoints

The checkpoint weights are intentionally not included in this folder.

Place the released files here with these names:

```text
checkpoints/
  teacher_msfe.pt
  srsn_z.pt
  ic_convtasnet_seat_id.pt
  ic_convtasnet_registration.pt
  sodas_gt_doa.pt
  sodas_reg_phase.pt
```

They can be uploaded as GitHub Release assets or stored with Git LFS.
